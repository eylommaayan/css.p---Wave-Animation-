# 🌊 Wave Animation Project

**Simple CSS Animation Using Transitions, Transforms & Keyframes**

פרויקט זה נוצר כחלק מהלימוד בקורס התכנות. הוא מדגים כיצד ניתן ליצור אפקט אנימציה מרשים באמצעות CSS בלבד — ללא JavaScript.

הפרויקט מתמקד בשלושה מושגים חשובים:

✅ שימוש באלמנטים "ילדים" (children)
✅ עבודה עם @keyframes
✅ יצירת אנימציה חלקה המבוססת על clip-path

---

## 📌 מה לומדים בפרויקט?

### 1. שימוש באלמנטים Children

האלמנט `<div class="wave">` מכיל שני אלמנטים מסוג `<h2>`.
לשניהם יש אותו טקסט — אך לכל אחד מוגדר עיצוב שונה.

הרעיון:

* הילד הראשון (child 1) יוצר outline של הטקסט באמצעות `text-stroke`.
* הילד השני (child 2) מקבל **אנימציה**.

כך מתקבל אפקט של טקסט שמתנגש עם "גל" צבעוני.

---

### 2. יצירת אנימציות בעזרת @keyframes

האנימציה מוגדרת באמצעות כלל `@keyframes wave`.

הוא כולל:

* **מצב התחלה (0%)**
* **מצב אמצע (50%)**
* **מצב סיום (100%)**

בכל שלב משתנה ערך ה־*clip-path* ליצירת אפקט זרימה.

דוגמה:

```css
@keyframes wave {
  0% {
    clip-path: polygon(...);
  }
  50% {
    clip-path: polygon(...);
  }
  100% {
    clip-path: polygon(...);
  }
}
```

---

### 3. שימוש ב־clip-path ליצירת תנועה

המאפיין `clip-path` שולח את הדפדפן "לחתוך" את האלמנט לפי צורה.
כאשר משנים את הצורה לאורך זמן — מתקבלת תנועה.

זה ערך חשוב לחיזוק ההבנה כי אנימציה אינה חייבת להיות translate או rotate בלבד — כל שינוי מתמשך הוא אנימציה.
